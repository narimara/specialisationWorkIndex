Assignment 1

Layout Design Experimentation 1

This design features a vertical split page layout with mouse controls on the left and the stave on the right. The stave reads from top to bottom because of my rhythm game inspiration which typically features note sequences falling from top to bottom. This was my first and simplest iteration of design and I worked on implementing each function very robotically, adding everything sequentially without much thought to the overall design.

Layout Design Experimentation 2

This design mirrors my base one with the same vertical split but this time mouse controls on the right and the stave on the left. My thinking behind this change was that users typically keep keyboard to the left and mouse to the right when using both. Since this synthesiser instrument is designed for 2 players, it is possible that they won't know each other well and won't be comfortable crowding physically into a small space. With this mirrored design, each user is closer to their input controls.

Layout Design Experimentation 3

This design experiments with a horizontal split rather than vertical. To further experiment, I also swapped the axis of the stave, to make the x position of notes equal timing and y equal pitch. This meant the playhead scrolling from top to bottom also has changed, and it now scrolls from left to right. Changing the design in this direction made sense to me since this is a much more common format of reading (music or otherwise).

Info Design Experimentation 1

With this design variation, I wanted to explore a less cluttered format of controls and instructions. I removed controls from the dialog and simply kept them in the left panel. In the panel, I removed the extra text explaining which buttons do what, hoping users could experiment with the controls to discover this themselves. This decision seemed fitting for the playful nature of this instrument.

Info Design Experimentation 2

This design explores different visual styles for the mouse controls. I rotated the sliders form horizontal to vertical and placed them in an outlined box to simulate the visual of a dj deck. I also changed the drop down menu for the waveforms into button a button selection, where the chosen one glows. I was curious to see what users preferred both visually and from an experience standpoint when it comes to small interaction changes like these.

Info Design Experimentation 3

In this final prototype I wanted to explore a different approach to revealing information to users. Once again inspired by a common game design choice, I opted for slowly revealing interactions as users try out the synth. I think this change really impacts the flow of using the instrument and can potentially add to the fun discovery elements.
